This project investigates the magnetic field produced by a circular current loop along its axis. To derive the magnetic field, we first use the Biot-Savart law analytically. Then, we divide the loop into a finite number of segments to numerically calculate the magnetic field. We compare the numerical results with the analytical solution to cross-check the results. We also perform a convergence study by changing the number of segments to examine the accuracy of the numerical method.
